AI Toolbox

Reusable agents, skills, and references live in two layers.

Layers

  • Local operating source: workspace root .agents/ (agents/, skills/, references/). Invoke these day-to-day.
  • Distributable layer: thijulio/thijulio-ai-toolbox. Assets are promoted here one at a time (never bulk-copy), each with ownership, portability, install path, and a smoke test.

When creating or changing a project

  1. Check .agents/agents/INDEX.md and .agents/skills/ before improvising.
  2. Architecture / stack decisions → invoke the software-architect agent. It anchors to this golden path and authors ADR drafts.
  3. New external repo → skills/create-external-repo; new workspace folder → skills/create-workspace-project.
  4. ADRs follow the toolbox template references/architecture-decision-record.md.
