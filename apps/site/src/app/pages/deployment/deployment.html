Deployment & Accounts

Provision accounts and infrastructure, respecting the golden path. What exists vs. what to create.

Prerequisites (human)

  • Publish dev-tooling (@thijulio/eslint-config, -tsconfig, -prettier-config) at v0.1.0.
  • Move painter-studio to ~/development/painter-studio + repo -> symlink (workspace-restructure).
  • Update linked-repos.yaml with aws-account-bootstrap, pet-management-platform-infra, maison-feline.

Human vs. agent

  • Agent can: install CLIs, run commands, create/edit config, create repo, run migrations, configure CI/CD, fill vars from provided secrets.
  • Only the human can: create accounts (sign-up), confirm email, approve paid plans, accept ToS, copy API keys from web panels. The agent has no browser, email, or credit card.
