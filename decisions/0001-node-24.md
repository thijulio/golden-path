# 0001 — Node 24 is the standard runtime

- **Status:** accepted
- **Date:** 2026-09-20

## Context

Repos were split between Node 22 (pet-management-platform, dev-tooling, website)
and Node 24 (thiago-smart-library, thijulio-ai-toolbox). A single standard removes
toolchain drift and the ">=22 vs >=24" guessing.

## Decision

Node 24 is the canonical runtime for every new project and tooling.

## Consequences

- New projects declare node >=24.
- Repos still on 22 are legacy; migrate to 24 when touched, don't start new work
  on 22.
